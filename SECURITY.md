# Security policy

This is a demonstration project, not a hardened internet-facing production API. Keep its published ports local unless you intentionally review and change the network configuration.

To report a security issue, use GitHub's **Report a vulnerability** option for this repository if private vulnerability reporting is enabled. Please avoid posting exploitable details in a public issue. Do not include secrets or personal data in reports.

The project has no application secrets and uses only standard-library HTTP servers. Keep base images and GitHub Actions updated; review Dependabot pull requests before merging.
